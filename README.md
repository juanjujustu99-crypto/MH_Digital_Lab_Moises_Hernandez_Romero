
# MH / Digital Lab

## Portafolio personal de Moises Hernandez

MH / Digital Lab es un sitio web personal desarrollado como parte de la actividad AVS.02.02.01 de la asignatura Aplicaciones Web.

El proyecto presenta mi perfil academico, areas de conocimiento y algunos de los proyectos desarrollados durante mi formacion en desarrollo de software.

## Secciones del sitio

- **Inicio:** Presentacion personal y areas de interes.
- **Sobre mi:** Formacion academica y evolucion de conocimientos.
- **Servicios:** Areas de trabajo y herramientas tecnologicas.
- **Portafolio:** Presentacion de StockManager, RunTrack y CityTour.
- **Contacto:** Informacion de contacto y formulario demostrativo.

## Tecnologias utilizadas

- HTML5
- CSS3
- Visual Studio Code
